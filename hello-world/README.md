# hello-world

The first test upload to this repository — minimal Python scripts.

## Files

| File | What it does |
| --- | --- |
| `hello.py` | prints `Hello, World!` |
| `hello2.py` | same idea, takes an optional name argument (defaults to `World`) |

## Run

```bash
python hello.py
python hello2.py          # Hello, World!
python hello2.py Ada      # Hello, Ada!
```

Hello, World!
